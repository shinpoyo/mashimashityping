# マシマシタイピング 🍜

ラーメン二郎の「コール」だけに特化したタイピングゲーム。

「ニンニク入れますか？」――その一言に、迷わず即答せよ。

▶ **プレイ:** https://shinpoyo.github.io/mashimashityping/

## 遊び方

1. 食券（難易度）を選ぶ
   - **小ラーメン**: 初心者向け・8ロット・短いコール中心
   - **大ラーメン**: 常連向け・10ロット・マシマシ解禁
   - **全マシマシ**: ジロリアン向け・12ロット・順不同・制限時間激短
2. 店員さんの問いかけに、表示されたコールをローマ字で打ち込む
3. 制限時間を過ぎると「ロット乱し」。コール通りの丼が出てくる

ローマ字は `shi/si`、`tsu/tu`、`nn/n`、`っ`（子音重ね / `ltu`）など一般的な表記に対応しています。

## 技術

- 素の HTML / CSS / JavaScript のみ（ビルド不要）
- 丼はコール内容に応じて SVG で動的描画
- 自己ベストは localStorage に保存
